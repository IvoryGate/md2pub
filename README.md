# md2pub

**写一次 Markdown，排成可以直接发布的小红书卡片。**

md2pub 是一个纯前端的 Markdown 排版工作台。左边写稿，右边实时分出封面与正文卡片；版式、配色、字体、页眉页脚都能调，最后按 1× / 2× / 3× 导出 PNG / JPG。

它不只是「把网页截成 3:4」：中文断行、分页、留白和层级都由一套可解释的排版引擎计算，目标是让每一屏都像被认真排过。

> 当前平台：**小红书卡片**。公众号富文本仍在规划中（顶栏入口已预留）。

---

## 功能

- **实时卡片分页**：按 1080 × 1440 原生尺寸测量，全局动态规划分页，避免「上一页很空、下一页很挤」。
- **KP 式中文排版**：禁则、标点挤压、行末/行首悬挂、中西文自动间隙，整段求最小松弛平方和。
- **完整封面系统**：6 种封面样式（经典 / 竖排 / 巨字 / 杂志 / 书封 / 索引），每种都可以叠加封面图，支持图上叠字 / 图文分开两种排版；文案与正文解耦，独立字号与边距。
- **颜色系统**：OKLCH 派生、5 种色相关系、冷暖纸色、亮/暗模式、9 组古典色，自动校验 WCAG 对比度。
- **工程标注**：六条尺寸线标注上/下/左/右/版心宽/版心高，导出时自动隐藏。
- **页眉页脚**：话题标签、页码、水印，各 6 个位置，文案、字号、字距、透明度可调。
- **发布文案**：根据正文与封面自动起草标题 / 正文 / 话题 / @ 账号，可继续修改；带 18 张图片上限提示与一键复制。
- **字体**：中文（文楷 / 宋体 / 黑体）与西文（跟随中文 / 系统 / 衬线 / 等宽）分开选择。
- **导入与导出**：PNG / JPG，1× / 2× / 3×；开发环境直接写入 `exports/`，也支持目录选择与 ZIP。
- **自定义**：自定义 CSS、样式预设保存、撤销/重做。
- **文档站**：内置设计文档、颜色文档、算法文档与一份完整示例，可从顶栏进入。

## 快速开始

要求 Node.js 20+。

```bash
npm install
npm run dev
```

打开终端输出的地址（默认 `http://localhost:5173/md2pub/`）。

生产构建：

```bash
npm run build
npm run preview
```

> 项目以 `/md2pub/` 为 base 路径部署，适合 GitHub Pages 子路径。若部署在根路径，请同步修改 `vite.config.ts` 的 `base`。

## 工作流

```text
Markdown
  → markdown-it token
  → 平台无关 Block 列表
  → 隐藏度量层（按卡片内容宽度真实渲染）
  → KP 断行（段内全局最优）
  → 动态规划分页（跨页全局最优）
  → 卡片组装（段落/列表按行续排）
  → 预览 / 导出
```

几个关键取舍：

- **测量与渲染同源**：度量层与最终卡片使用同一组件、同一宽度，避免「测出来和画出来不一样」。
- **先测量再分页**：分页是纯逻辑，不依赖 DOM；DOM 只负责提供真实高度。
- **卡片是原子**：标题、代码、公式、图、表格不跨页切开；段落和列表按行/条续排。
- **尺寸是数据**：版式参数与分页策略共享同一组数字，改字号不会让分页失控。

算法细节见 [排版算法](docs/typesetting-algorithm.md)。

```text
src/
  app/                 界面：App / Editor / Sidebar / XhsPreview / DocsPage
```

## 导出说明

- 预览缩放不影响导出；导出始终按原生 1080 宽渲染。
- 开发环境优先调用 `POST /__md2pub/export` 写入项目 `exports/`；生产环境没有该端点，会回退到目录选择器或 ZIP 下载。
- 图片、Mermaid、KaTeX 会先等待渲染稳定再截图，避免导出成半成品。
- 导出时参考线、编辑器高亮等辅助层自动隐藏。

## 已知限制

- 公众号富文本输出尚未实现。
- 表格与代码块不跨页；单块高于一页时会提示溢出。
- 西文断词只做整词保护，没有完整 hyphenation。
- 字体子集按需加载，首次测量可能略慢。
- 数据保存在浏览器 `localStorage`，换设备需要手动迁移。
